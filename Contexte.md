La méthode consiste en une injection conduite de courant sur câble, reproduisant de manière simple l'effet du couplage sur le câble d'un rayonnement. L'injection utilise une pince d'injection blindée formant avec le câble sous test un transformateur. Le couplage avec le câble est de nature inductive, le blindage supprimant tout couplage capacitif. Ainsi la sonde de courant est utilisée pour injecter des
ondes RF à faibles niveau dans un câble ou fil individuel. Le but de la méthode BCI est d’évaluer (sous certaines conditions) l’immunité électromagnétique d’un large panel d’équipements électroniques.

** Différents standards des tests BCI:
- ISO11452-4 pour le test d'équipements électroniques pour l'automobile
- DO-160G section 20 pour le test d'équipements électroniques pour l'aéronautique
- IEC62132-3 pour le test de circuits intégrés d'interface
